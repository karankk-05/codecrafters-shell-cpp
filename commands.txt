1. The Core Modes (How to stop typing over your own code)

i : Enter Insert Mode (to type code normally).

Esc : Return to Normal Mode (to navigate and execute commands). Always be in Normal Mode unless actively typing a word.

v : Enter Visual Mode (to highlight text).

2. Navigation (Stay on the home row)

h, j, k, l : Move Left, Down, Up, Right (Forget your arrow keys exist).

w : Jump forward by one word.

b : Jump backward by one word.

0 (Zero) : Jump to the beginning of the line.

$ : Jump to the end of the line.

gg : Jump to the very top of the file.

G : Jump to the very bottom of the file.

3. Editing at the Speed of Thought (In Normal Mode)

x : Delete a single character.

dd : Delete (cut) the entire line.

yy : Yank (copy) the entire line.

p : Paste the copied or deleted text below.

u : Undo.

Ctrl + r : Redo.

4. The "Action + Object" Combos (Vim's Superpower)
In Vim, you combine verbs (delete, change) with nouns (words, quotes, brackets).

cw : Change Word (Deletes the word your cursor is on and puts you in Insert mode).

ci" : Change inside quotes (Deletes everything inside " " and puts you in Insert mode. Incredible for editing strings).

di{ : Delete inside brackets (Instantly clears the contents of a C++ or Rust function block without deleting the { }).

5. Saving and Quitting

:w : Save (Write).

:q : Quit.

:wq : Save and Quit.

:q! : Force Quit without saving.

6. IDE Commands (Specific to your new LazyVim setup)

Space + e : Toggles the file explorer tree on the left.

Space + f + f : Find files (fuzzy search through your whole project).

Space + / : Search for specific text/variables across your entire project.
